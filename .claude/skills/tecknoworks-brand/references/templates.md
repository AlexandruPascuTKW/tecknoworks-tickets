# Tecknoworks Templates & Specifications

Detailed specifications for corporate stationery and communications materials.

## Business Card

### Dimensions
- **Size**: Standard business card (85 x 55 mm or 3.5 x 2 in)
- **Paper stock**: 300gr, simple, no textures

### Front Layout
```

│  │                                 │←8mm
│  │         [LOGO 30x9mm]          │ │
│  │                                 │ │
│  │                      23mm→      │ │
│  └─────────────────────────────────┘ │
└──────────────────────────────────────┘
```

### Back Layout
```
┌──────────────────────────────────────┐
│ ←8mm                                 │
```

### Typography
- **Employee Name**: Arial Rounded Bold 11pt, 9pt (alternate)

- **Text color**: Black

## Letterhead (A4)

### Dimensions
- **Size**: A4 (210 x 297 mm)
- **Paper stock**: Standard copy paper or quality letterhead paper

### Layout
```

│                          ←16mm        │
│                       [LOGO]          │←8mm

```

### Clear Space from Text to Edge
- **Top**: 8mm
- **Bottom**: 8mm
- **Left**: 16mm
- **Right**: 16mm

### Typography
- **Body text**: Arial Rounded 12pt, Black
- **Address/department**: Arial Rounded 10pt
- **Footer company info**: Arial Rounded 8pt, Arial Rounded Bold 10pt
